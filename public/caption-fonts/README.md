# Caption fonts

Unmodified fonts bundled for local previews and rendering. Each family's SIL Open
Font License is included in its directory.

- [TikTok Sans](https://github.com/tiktok/TikTokSans/releases/tag/v4.000): regular, bold, italic and bold italic, using the static 16pt optical-size family from the official v4.000 release, downloaded 2026-10-07. The internal family name is `TikTok Sans 16pt`; the app's setting is `tiktok-sans`. All four TTFs are used unchanged in both the browser and FFmpeg.

The following fonts come from the [Google Fonts repository](https://github.com/google/fonts), downloaded 2026-09-16:

- [Poppins](https://github.com/google/fonts/tree/main/ofl/poppins): regular, bold, italic and bold italic.
- [Anton](https://github.com/google/fonts/tree/main/ofl/anton): regular.
- [DM Serif Display](https://github.com/google/fonts/tree/main/ofl/dmserifdisplay): regular and italic.

The browser and FFmpeg load these same files locally. The legacy Classic sans option
continues to use the installed DejaVu Sans font with system fallback.
